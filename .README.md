# tp3-2324424 Déploiement d’une infrastructure multi-service sur AWS (Docker)

## Services déployés
- **Portainer** — Interface de gestion Docker
- **Jellyfin** — Serveur multimédia
- **Paperless-ngx** — Gestionnaire de documents

## Déploiement

1. Cloner le dépôt
```bash
git clone https://github.com/ton-user/tp3-2324424.git
cd tp3-2324424
```

2. Créer le fichier .env
```bash
cp .env.example .env
nano .env
```

3. Lancer les services
```bash
sudo docker compose up -d
```

4. Créer un compte administrateur Paperless
```bash
sudo docker compose run --rm webserver createsuperuser
```
